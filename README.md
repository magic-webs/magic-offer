# Welcome to your InstantDB NextJS app 👋

[InstantDB Docs](https://www.instantdb.com/docs)
[NextJS Docs](https://nextjs.org/docs)

This is a NextJS project scaffolded with create-instant-app.

To run the development server:
`npm run dev`

To push schema changes:
`npx instant-cli push`

To pull schema changes:
`npx instant-cli pull`

To (re)create the "default" company from the legacy global settings/prizes/spins
(run once after the first schema push, safe to re-run):
`npm run migrate:default-company`
